# 처음 쓰는 사람을 위한 mega-hwp 가이드

> 코딩을 몰라도 됩니다. "이 양식에 맞춰 결과보고서 채워줘"처럼 말로 부탁하면, AI가 한글(.hwp) 파일을 만들어 줍니다.
> 그림(구성도·흐름도·차트)은 짝꿍 플러그인 [mega-diagram](https://codeblack-inc.github.io/mega-diagram/)이 그리고, mega-hwp가 문서에 넣습니다. **둘을 같이 설치하세요.**

- 예시 문서 42종(1,300여 쪽): <https://codeblack-inc.github.io/mega-hwp/>
- 그림 예시: <https://codeblack-inc.github.io/mega-diagram/>

---

## 1. 무엇을 할 수 있나요

| 하고 싶은 일 | 이렇게 말하세요 |
|---|---|
| 빈 양식 채우기 | "첨부한 양식(.hwp)에 맞춰 중간보고서 채워줘. 자료는 이 파일들이야" |
| 새 문서 만들기 | "이 회의록·엑셀로 사업수행계획서 한글 파일 만들어줘. 30쪽 정도" |
| 한글 파일 읽기 | "이 hwp 내용을 정리해줘", "이 양식의 표 구조 알려줘" |
| 과제 산출물 | "요구사항분석서 / 시스템 설계서 / 시험결과서 / 사용자 지침서 만들어줘" |
| 그림 넣기 | "추진체계도·시스템 구성도·간트 차트도 그려서 넣어줘" (mega-diagram 필요) |

만들 수 있는 문서 종류와 목차는 갤러리에 모두 있습니다. 사업수행계획서, 중간·최종보고서, 월간보고서, 요구사항분석서, 설계서·명세서, 시험평가계획서·결과서, 실증계획서·결과보고서, 사용자·운용자 지침서, 응용표준안, 가명정보 처리대장, 보도자료, 전시회 증빙, 동영상 기획서 등입니다.

## 2. 어디서 쓰나요 — 내 상황에 맞는 길 고르기

| 나는… | 추천 방법 | 난이도 |
|---|---|---|
| **Claude**를 쓴다 (Pro·Max·Team) | **A. Claude 데스크톱 앱의 Code 탭** — 양식 채우기·한컴 검수까지 전부 | ★☆☆ 가장 쉬움 |
| Claude 앱·웹의 **채팅**만 쓴다 | **D. 채팅에 스킬 올리기** — 설치 없이, 새 문서 만들기 위주 | ★☆☆ |
| **ChatGPT**를 쓴다 (Plus·Pro·Team) | **B. Codex 앱** (ChatGPT 계정으로 로그인) | ★☆☆ |
| 터미널이 익숙하다 | C. Claude Code / Codex CLI | ★★☆ |

> Code 탭(또는 Codex)은 내 컴퓨터에서 직접 파일을 만들고 쪽마다 그림으로 찍어 검수하며, 한컴오피스 화면 검수까지 합니다. Claude **채팅**에서도 스킬 파일을 올리면 한글 파일을 만들어 내려받을 수 있습니다(D). chatgpt.com 채팅에서는 쓸 수 없고 Codex를 씁니다.

### 준비물 (한 번만)

1. **Node.js** (무료) — <https://nodejs.org> 에서 "LTS" 버튼을 눌러 설치. 다음, 다음만 누르면 됩니다.
2. (Mac, 권장) 쪽 그림 검수 도구: 터미널 앱을 열고 `brew install librsvg` — Homebrew가 없으면 건너뛰어도 문서는 만들어집니다. AI에게 "librsvg 설치해줘"라고 해도 됩니다.
3. (선택) 한컴오피스 한글 — 있으면 AI가 실제 한글 화면으로 한 번 더 검수합니다(Mac).

---

### A. Claude 데스크톱 앱 (가장 쉬움)

1. <https://claude.ai/download> 에서 Claude 앱 설치 → 로그인
2. 왼쪽 위에서 **Code** 탭 선택 → 작업할 폴더 고르기 (예: 바탕화면에 `과제문서` 폴더를 만들고 선택)
3. 입력창에 아래 네 줄을 **한 줄씩** 입력하고 Enter

   ```text
   /plugin marketplace add Codeblack-Inc/mega-hwp
   /plugin install mega-hwp@mega-hwp
   /plugin marketplace add Codeblack-Inc/mega-diagram
   /plugin install mega-diagram@mega-diagram
   ```

4. 앱을 다시 시작 (또는 새 대화)
5. 양식·자료 파일을 그 폴더에 넣고, 말로 부탁합니다 → [3. 이렇게 부탁하세요](#3-이렇게-부탁하세요)

> 명령을 치는 대신 "Codeblack-Inc/mega-hwp 플러그인이랑 Codeblack-Inc/mega-diagram 플러그인 설치해줘"라고 말해도 됩니다.

### B. ChatGPT 사용자 — Codex 앱

1. <https://openai.com/codex> 에서 Codex 앱 설치 → **ChatGPT 계정으로 로그인**
2. 작업할 폴더 열기
3. 앱 안의 터미널(또는 Mac의 터미널 앱)에 아래를 붙여 넣기

   ```bash
   codex plugin marketplace add Codeblack-Inc/mega-hwp
   codex plugin add mega-hwp@mega-hwp
   codex plugin marketplace add Codeblack-Inc/mega-diagram
   codex plugin add mega-diagram@mega-diagram
   ```

4. Codex를 다시 시작하고 말로 부탁합니다.

> **모델 오류가 나면** — `The '…' model is not supported when using Codex with a ChatGPT account.`
> ChatGPT 계정으로 로그인한 Codex는 쓸 수 있는 모델이 정해져 있습니다. 설정 파일 `~/.codex/config.toml`(Windows: `%USERPROFILE%\.codex\config.toml`)의 `model` 줄을 지원 모델로 바꾸세요.
>
> ```toml
> model = "gpt-5.5"
> ```
>
> 한 번만 바꿔 쓰려면 `codex -m gpt-5.5`. Codex 앱은 입력창 아래 모델 선택에서 고릅니다. 지원 모델은 요금제·시기에 따라 바뀌니, 오류가 나면 앱의 모델 목록에 보이는 것으로 고르세요.
> 조사가 필요한 요청은 인터넷 접근이 필요합니다. 터미널에서 `codex exec`로 실행할 때는 `-c sandbox_workspace_write.network_access=true`를 붙이세요.

### D. Claude 채팅에 스킬 올리기 (설치 없음)

1. 스킬 파일 내려받기: <https://codeblack-inc.github.io/mega-hwp/mega-hwp-skill.zip> (한글 엔진 포함, 약 4MB)
2. claude.ai(또는 Claude 앱) → 왼쪽 **사용자 지정** → **스킬** → **스킬 추가** → **스킬 업로드** → 받은 zip 선택 → 업로드
3. 설정 → 기능에서 **코드 실행과 파일 생성**이 켜져 있는지 확인
4. 새 채팅에서 말로 부탁하고, 완성된 .hwp 파일을 내려받습니다

> 채팅에서는 그림 플러그인(mega-diagram)과 한컴 화면 검수가 빠집니다. 그림이 많이 들어가는 문서나 양식 채우기는 A(Code 탭)를 권합니다.

### C. 터미널 (Claude Code / Codex CLI)

A·B와 명령이 같습니다. Claude Code는 `claude` 실행 후 `/plugin …` 네 줄, Codex CLI는 위 `codex plugin …` 네 줄.

## 3. 이렇게 부탁하세요

### 기본 원칙 3가지

1. **자료를 주세요.** 수치·일정·기관명은 AI가 지어내지 않고 준 자료에서만 가져옵니다. 제안서, 엑셀, 회의록, 이전 보고서를 폴더에 넣고 "이 폴더 자료로"라고 하세요.
2. **양식이 있으면 양식을 주세요.** 전담기관 양식(.hwp/.hwpx)이 있으면 그 목차·표를 그대로 채웁니다. 없으면 실제 정부과제 문서를 잰 표준 목차로 새로 만듭니다.
3. **분량과 용도를 말하세요.** "30쪽", "평가위원이 읽는 결과보고서", "내부 검토용 요약 5쪽" 등.

### 바로 쓰는 요청 예시

자료가 없어도 됩니다. 조사부터 시키면 AI가 찾아서 한글 파일까지 만듭니다.

```text
생성형 AI 신뢰성·안전 관련 국내외 정책 동향을 조사해서
5쪽 정도 정책 동향 보고서를 한글(.hwp) 파일로 만들어줘.
```

```text
첨부한 「2026 결과보고서 양식.hwp」에 맞춰 결과보고서를 채워줘.
자료: 계획서.hwp, 실적정리.xlsx, 회의록 폴더.
정량목표 표는 계획서의 평가비중을 그대로 쓰고, 그림은 구성도·간트·성과 차트 넣어줘.
```

```text
이 과제의 요구사항분석서를 만들어줘. 30쪽 정도.
요구사항은 기능·성능·인터페이스·데이터·보안으로 나누고 ID(SFR-001…)를 붙여줘.
먼저 목차랑 요구사항 목록부터 보여줘.
```

```text
사업수행계획서 Ⅲ장 추진체계에 들어갈 추진체계도와 추진 일정 간트 차트를 그려서 넣어줘.
```

### 진행 순서 (AI가 알아서 합니다)

1. 자료·양식 읽기 → 2. **목차와 핵심 문장을 먼저 보여 줌** (여기서 고칠 점을 말하세요) → 3. 그림 그리기(mega-diagram) → 4. 한글 파일 만들기 → 5. 쪽마다 그림으로 찍어 검수·수정 → 6. `.hwp`와 `.hwpx` 전달

## 4. mega-diagram과 같이 쓰면 좋은 이유

정부 문서는 쪽당 그림이 1개 안팎입니다(실제 문서 실측). 표와 글만으로 채운 문서는 평가위원 눈에 금방 AI 초안처럼 보입니다.

| mega-diagram이 그리는 것 | 문서에서 쓰는 곳 |
|---|---|
| 추진체계도·조직도 | 사업계획서 Ⅲ장, 결과보고서 추진체계 |
| 시스템 구성도·계층도·망 구성도·배포도 | 설계서, 계획서 Ⅳ장 |
| 흐름도·시퀀스·상태 전이 | 명세서, 연동 규격서, 지침서 |
| 간트·로드맵 | 추진 일정, 향후 계획 |
| 막대·선·도넛·레이더 차트 | 성과지표, 사업비, 시장 동향 |
| 화면 시안 | UI/UX 설계서, 사용자 지침서 |

- 그림은 투명 배경 PNG로 만들어져 한글 문서에 바로 들어갑니다. 문서 글자와 같은 남색·회색 톤입니다.
- 인쇄했을 때 그림 속 글자가 **9pt 이상**이 되도록 크기를 맞춥니다.
- 그림만 따로 필요하면: "이 내용으로 추진체계도 PNG만 만들어줘"

## 5. 자주 묻는 질문

**Q. 한컴오피스가 없어도 되나요?**
네. 파일은 한컴 없이 만들어집니다. 받은 파일은 한글·한컴독스·(보기 전용) 한글 뷰어로 엽니다.

**Q. 수치를 지어내지 않나요?**
준 자료에 없는 수치는 넣지 않고 "자료 필요"로 표시하거나 물어봅니다. 갤러리 예시는 설명을 위한 **가상 과제**(Jev·Kora)입니다.

**Q. 양식의 표가 깨지지 않나요?**
양식을 채울 때는 원래 표와 서체를 그대로 두고 칸 안만 채웁니다. 작성요령(파란 글씨 상자)은 지웁니다.

**Q. 목차 쪽번호가 한글에서 조금 달라요.**
쪽번호는 자동 계산값이라 한글에서 1~3쪽 차이 날 수 있습니다. 한글에서 열어 목차를 한 번 갱신하세요.

**Q. 보안이 걱정돼요.**
파일은 내 컴퓨터 폴더에서 만들어지고 저장됩니다. AI 서비스에 보내는 내용은 쓰는 Claude/ChatGPT 요금제의 데이터 정책을 따릅니다. 민감한 원본은 가명처리 후 쓰세요.

**Q. 안 될 때는?**
| 증상 | 해결 |
|---|---|
| `node: command not found` | 준비물 1의 Node.js 설치 후 앱 재시작 |
| 플러그인 명령이 안 먹음 | Claude는 **Code 탭**인지, ChatGPT는 **Codex**인지 확인 |
| 쪽 그림 검수가 안 됨 | `brew install librsvg` (Mac) — 없어도 파일은 만들어짐 |
| 그림이 문서에 없음 | mega-diagram 설치 확인, "그림도 넣어줘"라고 요청 |

문제·제안: <https://github.com/Codeblack-Inc/mega-hwp/issues>
