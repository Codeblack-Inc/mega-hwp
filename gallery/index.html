한글 문서 갤러리
설치 GitHub ↗

사업계획서와 결과보고서를 한글 파일 그대로. 빈 양식은 칸째로 채웁니다.

한국 정부과제 문서의 보고서체(□ ○ - ※ 개조식, 표 번호와 출처, 작성요령 상자)로 편집 가능한 .hwp/.hwpx를 만듭니다. 계획서·결과보고서뿐 아니라 설계서·명세서·시험결과서·지침서·표준안·홍보 자료까지, 가상 과제 두 개(Jev·Kora)의 산출물을 실제 분량으로 담았습니다. 아래 예시는 모두 JSON 하나로 생성했고, 한컴오피스에서 열어 확인했습니다. 쪽마다 원본 JSON과 파일을 받을 수 있습니다.


    

  






  

    

      
HOW IT WORKS

      
    
        
  1. 파악
    첨부한 .hwp/.hwpx를 마크다운으로 읽습니다. 작성요령과 자리표시가 있으면 양식으로 보고 채우기로, 아니면 새 문서로 진행합니다. 수치는 소스에서만 가져옵니다.
    2. 
        
  2. 목차 확인
    장·절 제목과 핵심 문장을 먼저 보여 드립니다. 양식이면 양식의 목차를 그대로 따릅니다.
    3. 
        
  3. doc.json · fill.json
    □○-·※ 기호 줄, 표, 요약 상자로 본문을 쓰거나, 라벨 옆 칸·제목 뒤 본문·작성요령 삭제를 지정합니다.
    4. 
        
  4. 빌드와 검수
    rhwp(Rust+WASM)로 .hwp를 만들고, 쪽마다 이미지로 렌더링해 AI가 직접 봅니다. macOS에서는 한컴오피스 화면을 캡처해 실제 조판까지 확인합니다.
    5. 
      

    

    

      
INSTALL

      
Claude Code

      
/plugin marketplace add Codeblack-Inc/mega-hwp
/plugin install mega-hwp@mega-hwp

      
Codex

      
codex plugin marketplace add Codeblack-Inc/mega-hwp
codex plugin add mega-hwp@mega-hwp

      
처음이세요? 초보자 가이드 — Claude 앱(Code 탭)·ChatGPT(Codex)에서 설치하고 말로 부탁하는 법. 그림은 mega-diagram을 같이 설치하면 구성도·차트까지 넣어 줍니다.

      
/plugin marketplace add Codeblack-Inc/mega-diagram
