# doc.json / fill.json

## doc.json

```json
{
  "kind": "plan",
  "theme": { "body": "휴먼명조", "size": 13 },
  "blocks": [ { "type": "…" } ]
}
```

`kind`는 `lint` 기준만 바꾼다: `plan`(계획서, 기본) · `report`(결과·중간·월간 보고, 회의 결과 — 숫자 든 줄 45%까지) · `press`(보도자료 — 서술문 허용, 표 비율 검사 안 함).

### 블록

| type | 필드 | 모양 |
|---|---|---|
| `title` | `text`, `sub`, `date`, `org` | 표지. 테두리 상자 속 제목(22pt) + 부제, 아래쪽에 날짜·기관. 다음 블록은 새 쪽 |
| `chapter` | `text` (`"Ⅰ. 사업 개요"`) | 장 제목 띠: 진한 번호 칸 + 제목 칸 (HY헤드라인M 16). 번호가 없으면 `h1` |
| `section` | `text` (`"① 과제목표"`, `"2 추진절차"`) | 소단원 띠: 번호 칸 + 제목 칸 (HY헤드라인M 13) — 결과보고서 양식의 ①②③④ |
| `h1` | `text` | 번호 없는 큰 제목 (HY헤드라인M 16) |
| `h2` | `text` | 절 `"1. 추진 배경 및 필요성"` (휴먼명조 굵게 15) |
| `h3` | `text` | 항 `"가. 추진 배경"` (휴먼명조 굵게 13) |
| `text` | `lines` (배열 또는 `\n` 문자열) | 기호로 시작하는 줄 → 수준별 서체·크기·내어쓰기. 빈 줄은 간격 |
| `table` | `header`, `rows`, `widths`, `align`, `merge`, `caption`, `note`, `sideHeader`, `fills`, `size`, `width` | 표 (맑은 고딕 10, 머리행 회색). 아래 참고 |
| `box` | `title`, `lines` | 연한 배경 상자 (핵심 요약·시사점) |
| `guide` | `title`(기본 `< 작성요령 >`), `lines` | 파란 글자 상자 (양식 만들 때) |
| `image` | `path`(doc.json 기준), `width`(mm, 기본 150), `caption` | PNG/JPEG, 가운데 정렬, 아래 이름표 `< 이름 >` |
| `pagebreak` | | 다음 블록을 새 쪽에서 시작 |

### text 줄 기호

| 기호 | 수준 | 글자 | 쓰임 |
|---|---|---|---|
| `□` `■` | 0 | 휴먼명조 14 굵게 | **제목구** (15자 이내, "기술적 제약요인") |
| `○` `ㅇ ` `◦` | 1 | 휴먼명조 14 | 요지 한 줄 (40자 이내) |
| `- ` | 2 | 휴먼명조 13 | 근거·방법·수치 1~2줄 (○보다 많게) |
| `⇒` | 2 | 13 | 결론·시사점 ("⇒ … 필요") |
| `·` `•` | 3 | 12 | 보충 |
| `※` | 2 | 11 | 기준·출처·단서 |
| `* ` | 3 | 11 | 각주성 설명 |

- 기호 뒤에는 한 칸 띄운다. `-1%`, `*중요*`처럼 붙어 있으면 기호로 보지 않는다.
- `**굵게**`로 강조한다. 한 쪽에 1~2곳만.
- 기호 없는 줄은 들여쓰기 없는 본문 문단.

### table

```json
{ "type": "table", "caption": "사업 목표 및 성과지표",
  "widths": [2, 4, 2, 2], "align": "clcc",
  "header": ["구분", "성과지표", "현재", "목표"],
  "rows": [["정량", "처리 시간", "11.5분", "4.4분"], ["", "정확도", "71%", "92%"]],
  "merge": [[1, 0, 2, 0]],
  "note": "※ 출처: 내부 측정(2025)" }
```

- `widths`: 열 너비 비율. `width`: 본문 폭 대비 표 폭(기본 1).
- `align`: 열마다 `l`/`c`/`r` 한 글자. 머리행·`sideHeader` 열은 항상 가운데.
- `merge`: `[시작행, 시작열, 끝행, 끝열]` (0부터, `header` 행 포함). 가려진 칸 내용은 무시된다.
- `caption`: 표 위에 `< 이름 >` (샘플 방식, 번호 없음). `theme.captions: "numbered"`면 `<표 n> 이름`. 직접 `<표 3-1> …`로 쓰면 그대로.
- 금액 표는 단위를 표 위에: `{"type":"text","lines":["(단위 : 천원)"]}` 또는 `note`.
- 칸 안에서도 `\n`, 기호 줄, `**굵게**`를 쓸 수 있다.
- `fills`: `{"행,열": "#색"}` 칸 배경. `size`: 글자 pt (기본 10).

### theme

| 키 | 기본값 | |
|---|---|---|
| `body` | 휴먼명조 | □ ○ - · 본문, 절·항 제목 |
| `head` | HY헤드라인M | 장·소단원 띠, 표지 |
| `table` | 맑은 고딕 | 표·상자 |
| `note` | 휴먼명조 | ※ |
| `size` | 13 | 본문(-) pt — □·○는 +1, ·는 −1, ※는 −2 |
| `tableSize` | 10 | 표 글자 pt |
| `lineSpacing` | 160 | % |
| `accent` | `#1F3864` | 장·소단원 번호 칸, 상자 선 |
| `headerFill` | `#D6D6D6` | 표 머리행 (샘플 1위 회색) |
| `soft` | `#F2F2F2` | 요약 상자 |
| `guide` | `#1F4FC1` | 작성요령 글자 |
| `captions` | `"label"` | `"label"` = `< 이름 >` · `"numbered"` = `<표 1> 이름` |
| `page` | `{left:20,right:20,top:15,bottom:15,header:10,footer:10}` | 용지 여백 mm (A4, 본문 폭 170mm) |

## fill.json

```json
{
  "cells": [
    { "label": "과업명", "text": "온라인 예약 시스템 고도화" },
    { "label": "성명", "nth": 2, "text": "홍길동" },
    { "label": "사업 추진계획", "below": true, "text": "□ 예약 시스템 고도화" },
    { "sec": 0, "para": 17, "ctrl": 0, "row": 2, "col": 0, "text": "○ 모바일 화면 개편\n- 결제 단계 5→3단계" }
  ],
  "replace": [ { "find": "(Ⅱ번 항목 최소 2페이지 이상 작성)", "with": "" } ],
  "fields": { "누름틀이름": "값" },
  "removeTables": ["< 작성요령 >"],
  "insert": [
    { "after": "1. 사업목표", "blocks": [ { "type": "text", "lines": ["○ …", "- …"] } ] }
  ],
  "theme": { "body": "휴먼명조" }
}
```

적용 순서: `fields` → `cells` → `replace` → `removeTables` → `insert`. 표 주소는 **원본** `text` 출력 기준이다(`cells`가 먼저 실행되므로).

- `cells`: 라벨 칸(공백 무시, 완전 일치)의 오른쪽 칸, `below`면 아래 칸. 같은 라벨이 여럿이면 `nth`(1부터). 또는 `text` 출력의 `sec`·`para`·`ctrl`과 `row`·`col`. 칸의 기존 내용은 지우고, 원래 서체·크기·정렬을 따른다.
- `replace`: 본문과 표 안의 같은 문구를 모두 바꾼다.
- `removeTables`: 이 문구가 든 표를 통째로 지운다.
- `insert`: `after` 문구를 포함한 첫 본문 문단 뒤에 `blocks`(doc.json과 같은 블록)를 넣는다. 바로 뒤에 이어지는 빈 줄·기호만 있는 자리표시 줄(`ㅇ`, `-`, `*`, `‧`)은 지운다. 지우지 않으려면 `"dropPlaceholders": false`.
