# 보고서체 기준

실제 한국 정부과제 문서 12종(사업계획서 4, 결과·중간보고서 5, 월간보고 1, 연구개발계획서 1, 시행계획 공고문 1, 약 900쪽)을 분석한 결과다. 테마 기본값은 이 문서들에서 가장 흔한 조합이다.

## 개조식 위계

| 기호 | 쓰임 | 12종 합계 |
|---|---|---|
| `□` | 주제 문장. 그 단락의 결론을 한 줄로 | 약 190회 |
| `○` / `ㅇ` | 항목 | 약 1,190회 |
| `-` | 세부 내용·근거 수치 | 약 3,700회 |
| `·` / `‧` | 보충 | 문서마다 다름 |
| `※` / `*` | 기준·출처·단서 | 약 400회 |

- `-` 줄이 가장 많다. 근거는 `-` 줄에서 숫자와 함께 댄다.
- `□` 아래 `○` 2~4개, `○` 아래 `-` 1~3개가 보통이다. `□` 하나에 `○` 하나면 `□`를 빼고 `○`로 올린다.
- 종결은 명사형: "~ 확보", "~ 구축", "~ 필요", "~ 예정". 서술형("~합니다")은 쓰지 않는다.
- 괄호 소제목으로 항목을 여는 형식이 흔하다: `- (실증 대상) 삼성…`, `○ (1차년도) …`.

## 서체와 크기

| 역할 | 서체 | 크기 |
|---|---|---|
| 장·절 제목, `□` | HY헤드라인M | 15~16pt |
| 본문 `○ -` | 휴먼명조 (또는 바탕체·한양신명조) | 13pt, 줄 간격 160% |
| 표 | 맑은 고딕 · HY중고딕 | 10~11pt |
| `※` 주석 | 맑은 고딕 | 10~11pt |

한컴오피스에는 위 서체가 모두 들어 있다. 다른 서체가 필요하면 `theme`에서 바꾼다.

## 표
- 표 위 가운데에 `<표 n> 제목`, 표 아래 오른쪽에 `※ 출처:` 또는 `(단위: 천원)`.
- 머리행은 옅은 회청색 배경, 가운데 정렬, 굵게. 첫 열이 구분 항목이면 `sideHeader`.
- 같은 값이 세로로 이어지면 `merge`로 합친다 (구분·단계·연도).
- 일정표는 분기·월 칸에 `●` 또는 `■`.

## 양식
- 정부 양식의 파란 `< 작성요령 >` 상자는 **"삭제 후 제출"**이 원칙이다 → `removeTables`.
- 양식은 제목 뒤에 `ㅇ`, `-`, `*`만 있는 자리표시 줄을 둔다. `insert`가 이 줄들을 지우고 내용을 넣는다.
- 라벨-값 표(과업명, 기관명, 책임자 …)는 `cells`의 `label`로 채운다.
- 양식의 장 번호·제목·표 구조는 바꾸지 않는다. 분량 지시("최소 2페이지 이상")가 있으면 지킨다.
